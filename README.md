
# 📊 Freelance Rate & Project Calculator

A lightweight, high-performance web utility built to help freelancers, contractors, and agency owners calculate minimum hourly rates and project estimates based on financial goals.

![Project Status](https://img.shields.io/badge/Status-Live-success)
![License](https://img.shields.io/badge/License-MIT-blue)

---

## ✨ Features
* **Dynamic Calculations:** Instant, client-side hourly rate and project quote estimation using custom JavaScript.
* **Overhead Protection:** Incorporates non-billable hours, software expenses, and profit targets into baseline rates.
* **Zero Dependencies:** Built with pure HTML, CSS, and Vanilla JS for maximum loading speed and high SEO scores.
* **Monetization Ready:** Built-in recommendations for freelance tools (invoicing, international transfers, legal templates).

---

## 🛠️ Tech Stack
* **Markup:** HTML5
* **Styling:** CSS3 (Modern Flexbox & CSS Grid, Responsive Design)
* **Logic:** Vanilla JavaScript (ES6+)
* **Hosting:** GitHub Pages
